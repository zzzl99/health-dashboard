THE THREE-MONTH VIEW

从恢复开始，慢慢变强。

2026.10.26 — 2027.01.25
01 / 建立节奏

先睡好，再练稳

午夜前入睡，平均睡眠向 7–7.5 小时靠近。每周三次轻松跑、三次短力量，先不加跑量。

02 / 逐步积累

规律比强度重要

睡眠向 7.5–8 小时靠近。恢复良好才延长一趟跑步或增加力量阻力，每次只改一个变量。

03 / 长久坚持

找到自己的节奏

争取舒适完成 40–50 分钟轻松跑，保持力量习惯。进阶不是配额，睡眠不足就保持或减量。

力量训练动作卡

A · 全身基础
椅子深蹲、墙面俯卧撑、臀桥、死虫。

B · 髋背与稳定
髋铰链、轻背包划船、扶椅分腿蹲、侧桥。

C · 轻量巩固
墙面俯卧撑、轻背包划船、鸟狗。

每项先做 1–2 组，通常 6–12 次，保留约 3 次余力。侧桥每侧 15–25 秒。动作疼痛就停止。

让恢复决定今天的强度

跑步保持能说完整句子，用力感约 3–4/10，允许跑走交替。

前晚睡眠不足 6 小时或明显疲劳，训练改为散步或休息，不在次日补课。

14:00 后少摄入咖啡因，午睡控制在 20–30 分钟。运动尽量在 20:30 前结束。

力量训练需手环或 Fitbit 记录为力量类活动才能识别。无法从步数推断完成了力量训练。
